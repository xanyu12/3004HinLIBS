INSTRUCTIONS:
To checkout an item, press Browse, select check out mode and double click a book to select it.
To place a hold, press Browse, select place hold mode and double click a book to select it.
To cancel a hold, press My Items and double click an item on the My Holds table to remove your hold.
To checkin an item, press My Items and double click and item on the My Loans table to return it.
AS LIBRARIAN:
To add item, press Add Item, fill out necessary fields and press the add button at the bottom, you can check that it has been added in the catalogue table in 'Remove Item'.
To remove an item, press Remove Item, double click a row and then it will be deleted from the catalogue.
To check in an item for a user, press Manage Patron Items, enter a patrons library card number (see patron accounts above) and press search. The table will populate with the patrons loans (if there are any). Double click a row to return an item for that user.
